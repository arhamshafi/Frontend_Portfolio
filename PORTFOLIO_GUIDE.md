# Premium Developer Portfolio - Muhammad Arham Shafi

## 🎨 Design Overview

This is a premium, modern, and highly professional developer portfolio website built with React, Tailwind CSS, and Framer Motion. The design features a dark theme with purple accents, creating a sophisticated and contemporary look.

## ✨ Features

- **Ultra Modern UI**: Clean, minimal design with smooth animations
- **Dark Theme**: Black background with purple (#8b5cf6) accent colors
- **Fully Responsive**: Optimized for mobile, tablet, and desktop
- **Smooth Animations**: Powered by Framer Motion
- **Production Ready**: Clean code and optimized performance

## 🎯 Customization Guide

### 1. Update Personal Information

Edit \`src/Data.js\`:
- Update project details (add live links, GitHub links, images)
- Modify skills and proficiency levels
- Customize services offered

### 2. Update Contact Information

Edit \`src/components/Contact.jsx\` and \`src/components/FooterSection.jsx\`:
- Replace email: \`arhamshafi@example.com\`
- Update GitHub: \`https://github.com/arhamshafi\`
- Update LinkedIn: \`https://linkedin.com/in/arhamshafi\`

### 3. Add Project Images

Place project images in \`public/\` folder and update the \`image\` field in \`projectsData\` in \`src/Data.js\`.

### 4. Customize Colors

The portfolio uses purple as the primary color. To change:
- Edit CSS variables in \`src/index.css\`
- Update Tailwind classes (purple-500, purple-600, etc.)

### 5. Add Resume/CV

Update the resume link in the Hero or Contact section to link to your PDF resume.
